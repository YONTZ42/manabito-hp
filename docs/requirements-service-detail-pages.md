# サービス詳細ページ追加要件

## 概要

`ServiceDetailsSection` から遷移できる詳細ページを追加する。  
ホームの世界観と導線を保ちながら、各サービスの個別ページを `app` ルーティング配下に配置する。

## 目的

- サービスカードから詳細ページへ遷移できるようにする
- 現在 `#` になっているリンクを実ルートへ置き換える
- 詳細ページの大枠だけを先行実装し、後から中身を追加しやすくする
- ホームと同じトーンのレイアウトで統一感を保つ

## 対象ページ

- `/services/administration-support`
- `/services/inspection-training`
- `/services/experiential-learning`
- `/services/seminars-training`

## ルーティング要件

- Next.js App Router のルールに従い、`app/services/<service-name>/page.tsx` の個別ページとして配置する
- 各詳細ページは明示的な静的ルートを持ち、一覧から別ページへ遷移する構成にする
- ローディング UI は `app/services/loading.tsx` で共通化する
- 遷移導線は既存 `Button` を使い、サービス一覧から個別ページへ移動できるようにする

## UI要件

- 各詳細ページは `Header` / `Footer` を含む
- ファーストビュー、概要、提供内容、進行イメージ、CTA の大枠を配置する
- 背景装飾、余白、カード表現はホームの既存スタイルに合わせる
- 具体的な原稿や実績、FAQ、料金などは後続追加を前提とし、プレースホルダー構成に留める

## 連携要件

- `ServiceDetailsSection` の各カードに詳細ページへのリンクを設定する
- サブページからでもホーム内セクションへ戻れるよう、ヘッダー導線は `/#section-id` 形式に統一する

## 実装メモ

- サービス情報は配列データとして共通管理する
- 一覧表示と詳細ページ表示の両方で同じデータを参照する
- ページごとの metadata は対象サービスに応じて出し分ける
