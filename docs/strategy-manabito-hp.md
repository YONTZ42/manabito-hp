# 合同会社マナビト WEBサイト戦略設計書

---

## 0. 本書の位置づけ

本書は、合同会社マナビトのWEBサイト（https://www.manabito.info/）が**何を達成すべきか**、**誰に何を伝えるべきか**、**どう行動させるべきか**を定義する戦略ドキュメントである。技術設計（`design-manabito-hp.md`）・要件定義（`requirements-manabito-hp.md`）とは独立し、サイト改善の意思決定基盤として機能する。

---

## 1. サイトの存在意義

### 1-1. ビジョン

> **「社会を、大きな教室に。」を実現するための、最初の接点になる。**

マナビトのWEBサイトは単なる名刺代わりではない。行政・政治・教育・企業の担当者が「こういう支援が欲しかった」と感じ、**問い合わせという行動に踏み出す装置**である。

### 1-2. サイトが果たすべき3つの役割

| 役割 | 内容 |
|------|------|
| **認知** | 「合同会社マナビト」という存在と、その専門領域を知ってもらう |
| **信頼** | 代表の経歴・実績・理念を通じて「この人に任せたい」と思わせる |
| **行動** | 問い合わせフォーム送信 or 電話発信というコンバージョンを生む |

---

## 2. 達成目標（KGI / KPI）

### 2-1. 最終目標（KGI）

**月間問い合わせ件数の安定的な獲得**

サイト経由での問い合わせ（フォーム送信 + 電話発信）を継続的に生み出し、マナビトの事業成長を支える集客チャネルとして機能させる。

### 2-2. 中間指標（KPI）

| 指標 | 計測方法 | 意味 |
|------|----------|------|
| 月間セッション数 | GA4 | サイトへの流入量。認知の広がりを測る |
| 問い合わせフォーム送信数 | GA4イベント / Resend送信ログ | 最重要コンバージョン |
| 電話タップ数 | GA4 `tel:` クリックイベント | モバイルからの直接問い合わせ意思 |
| サービス詳細ページ閲覧率 | GA4 ページビュー | サービスへの関心度 |
| 平均滞在時間 | GA4 | コンテンツの引力 |
| 直帰率 | GA4 | ファーストビューの訴求力 |

### 2-3. 目標達成のための3本柱

```
①流入を増やす ─→ ②関心を深める ─→ ③行動させる
  (SEO・SNS)      (コンテンツ)       (CTA設計)
```

## 3. ターゲット定義

### 3-1. プライマリーターゲット

#### A. 行政職員（子ども・若者政策担当）

- **役職**: 市区町村の子ども・若者政策課、企画課、教育委員会の担当者
- **課題**: こども基本法の施行に伴い、子ども・若者の意見反映が求められているが、対話の場の設計方法がわからない。庁内調整も煩雑
- **検索行動**: 「子ども 意見反映 方法」「若者参画 事例」「こども基本法 意見聴取」
- **決裁構造**: 担当者が情報収集 → 上長に提案 → 予算確保 → 発注。サイトは「提案資料に貼れる情報源」でもある
- **刺さるメッセージ**: 対話の設計から実施まで伴走する。担当者が一人で抱え込まなくていい

#### B. 地方議員（行政視察・研修を企画する立場）

- **役職**: 市区町村議会議員、会派の研修担当
- **課題**: 先進自治体への視察を企画したいが、視察先の選定・アポ取り・行程調整に手が回らない
- **検索行動**: 「議員研修 視察 企画」「行政視察 コーディネート」「地方創生 先進事例 視察」
- **決裁構造**: 会派内で合意 → 議会事務局経由 → 政務活動費で支出。実績と信頼性が重要
- **刺さるメッセージ**: テーマ設定から行程設計、現地調整まで丸ごとお任せ。学びを持ち帰れる視察を設計する

### 3-2. セカンダリーターゲット

#### C. 企業の人事・研修担当

- **課題**: 社員研修やチームビルディングを外部委託したいが、自社の課題にフィットする研修が見つからない
- **検索行動**: 「社員研修 外部講師」「人材育成 セミナー 企画」「体験型研修 地域」
- **刺さるメッセージ**: 御社の現場課題に合わせた研修を、企画から実施まで一括で設計する

#### D. 学校・教育機関の教員・管理職

- **課題**: 体験学習や校外学習を実施したいが、受入先の開拓・調整・プログラム設計の時間がない
- **検索行動**: 「体験学習 プログラム」「農業体験 学校」「工場見学 学習」
- **刺さるメッセージ**: 地域の現場と学校をつなぎ、子どもの学びが深まる体験を設計する

### 3-3. ターゲット別・サイト内導線

```
行政職員 ──→ お悩みセクション(悩み1,4) ──→ 「若者とマナブ」詳細 ──→ 問い合わせ
地方議員 ──→ お悩みセクション(悩み2)   ──→ 「事例をマナブ」詳細 ──→ 問い合わせ
企業担当 ──→ お悩みセクション(悩み3)   ──→ 「講座でマナブ」詳細 ──→ 問い合わせ
学校関係 ──→ お悩みセクション(悩み3)   ──→ 「現場でマナブ」詳細 ──→ 問い合わせ
```

## 4. コアメッセージ戦略

### 4-1. メッセージ階層

```
Lv.1 ブランドメッセージ（理念・世界観）
  └─ Lv.2 バリュープロポジション（なぜマナビトなのか）
       └─ Lv.3 ターゲット別メッセージ（個別の課題解決）
            └─ Lv.4 CTA（行動喚起）
```

### 4-2. Lv.1 ブランドメッセージ

> **「社会を、大きな教室に。」**

教室の中だけで教育は完結しない。行政も、企業も、地域も、すべてが学びの場になる。マナビトはその橋渡しをする存在である。

**このメッセージが伝えるべきこと:**

- 教育を「学校の中の話」に閉じない視座の広さ
- 行政・地域・企業を巻き込む実行力
- 子どもから大人まで、立場を超えた「共に学ぶ」姿勢

### 4-3. Lv.2 バリュープロポジション

> **「企画から運営まで、ワンストップで伴走。」**

マナビトの最大の価値は**伴走**である。アイデアの壁打ちから、関係者調整、当日運営、事後の振り返りまで、一貫して寄り添う。

**競合との差別化ポイント:**

| 差別化要素 | 内容 |
|------------|------|
| **教育者の視点** | 代表が元高校教員。「人を育てる」プロの目線で設計する |
| **行政連携の実行力** | NPO代表として行政との協働実績がある。行政の言葉がわかる |
| **ワンストップ** | 企画・調整・運営・振り返りまで丸投げできる。担当者の負担を最小化 |
| **現場主義** | 机上の提案ではなく、現場に入り込んで一緒に動く |

### 4-4. Lv.3 ターゲット別メッセージ

#### 行政職員向け

| 要素 | 内容 |
|------|------|
| 恐れ | 「子どもの声を聞け」と言われても、やり方がわからない。失敗したら批判される |
| 共感 | やりたいことはある。でも、時間も人手もノウハウも足りない |
| 解決 | 対話の場の設計から意見の整理、施策への接続まで伴走する |
| 証拠 | 元教員 × NPO代表。教育と行政の両方の言葉で橋渡しできる |
| 行動 | まずは現状の課題をお聞かせください。一緒に進め方を考えます |

#### 地方議員向け

| 要素 | 内容 |
|------|------|
| 恐れ | 視察を企画しても、段取りに追われて「学び」が薄くなる |
| 共感 | 先進事例を学びたいが、視察の調整に手が回らない |
| 解決 | テーマの言語化から視察先調整、行程設計、事後整理まで一括サポート |
| 証拠 | 行政・教育の現場を熟知した視点で、ただの「見学」ではなく「学びのある視察」を設計 |
| 行動 | 視察のテーマや候補地のご相談からお気軽にどうぞ |

#### 企業向け

| 要素 | 内容 |
|------|------|
| 恐れ | 汎用的な研修では社員に響かない。現場の課題とズレる |
| 共感 | 自社に合った研修を探しているが、どこに頼めばいいかわからない |
| 解決 | 御社の課題に合わせたオーダーメイドの研修を、企画から実施まで設計 |
| 証拠 | 教育のプロが「人が変わる瞬間」を設計する。テンプレート研修とは違う |
| 行動 | 研修の目的やお悩みをお聞かせください |

### 4-5. Lv.4 CTA（行動喚起）メッセージ

**現在のCTA:** 「まずはお気軽にご相談ください」

**強化案:**

| 場所 | CTA文言 | 意図 |
|------|---------|------|
| ヒーロー直下 | まずは相談してみる | 心理的ハードルを下げる。「見積もり」ではなく「相談」 |
| サービス詳細ページ末尾 | この分野について相談する | サービスへの関心が高まった直後に行動を促す |
| 代表紹介セクション直後 | この人に相談してみる | 信頼感が高まった瞬間を逃さない |
| フッター上 | 「やりたいこと」を一緒に形にしませんか？ | サイト全体を読み終えた人への最終アプローチ |

## 5. コンテンツ戦略

### 5-1. 現状のコンテンツ評価

| セクション | 評価 | 課題 |
|------------|------|------|
| ヒーロー | 良い。世界観が伝わる | リード文がやや長い。一文で刺す力が欲しい |
| お悩み | 良い。ターゲットの自分ごと化ができている | 悩みの数が4つに増えており、優先度が分散 |
| サービス | 構成は良い。横スライドで一覧性がある | 「結局何をしてくれるのか」の具体性がもう一段欲しい |
| サービス詳細 | 丁寧に設計されている | 料金目安・所要期間・事例がないため、問い合わせの心理的ハードルが高い |
| 代表紹介 | ストーリーが秀逸。共感を生む構成 | 具体的な実績数字（支援自治体数、研修実施回数等）があると信頼度が跳ねる |
| Instagram/お知らせ | 更新性を示す意図は正しい | お知らせが「準備中」のまま。更新されないSNSセクションは逆効果になりうる |
| 問い合わせ | 電話・フォームの2導線は適切 | フォームの項目が多すぎると離脱する。最小限にすべき |

### 5-2. 追加すべきコンテンツ（優先度順）

#### 優先度A（効果が高く、すぐに着手可能）

1. **実績・数字の明示**
   - 支援自治体数、研修実施回数、参加者数など
   - 「実績ゼロに見える」状態は行政・企業の担当者にとって最大の不安材料
   - 概数でもいいので数字を出す（例：「行政連携プロジェクト ○件以上」）

2. **導入事例・お客様の声**（1〜2件でも可）
   - 「どんな課題を持つ自治体/企業が」「どんな支援を受けて」「どう変わったか」
   - 匿名・概要レベルでも効果がある
   - 行政担当者は「他の自治体がやっている」という事実に最も動かされる

3. **お知らせの実運用**
   - 「準備中」は信頼を損なう。最低でも1件は掲載する
   - 月1回の更新で十分。活動報告、メディア掲載、登壇情報など

#### 優先度B（中期的に取り組むべき）

4. **料金体系の目安**
   - 「要相談」でもいいが、「初回相談無料」「視察研修の企画：○万円〜」など目安があると問い合わせのハードルが下がる

5. **よくある質問（FAQ）**
   - 「どのエリアに対応していますか？」「最低何人から対応可能？」「準備期間はどれくらい？」
   - 問い合わせ前の不安を先回りして解消する

6. **ブログ / コラム**
   - SEO流入の柱。「こども基本法 意見反映 方法」等のキーワードで記事を書く
   - 専門性の証明にもなる

### 5-3. SEOキーワード戦略

#### メインキーワード（サービスページで狙う）

| キーワード | 検索意図 | 対応ページ |
|------------|----------|------------|
| 子ども 意見反映 支援 | 行政担当者が方法を探している | 若者とマナブ |
| 議員研修 視察 企画 | 議員が視察の外部委託先を探している | 事例をマナブ |
| 行政視察 コーディネート | 視察の段取りを任せたい | 事例をマナブ |
| 体験学習 プログラム 企画 | 学校が体験学習の企画を探している | 現場でマナブ |
| 社員研修 外部 企画 | 企業が研修の外注先を探している | 講座でマナブ |
| こども基本法 意見聴取 | 法制度対応を調べている行政職員 | 若者とマナブ |

#### ロングテールキーワード（ブログ/コラムで狙う）

- 「こども基本法 自治体 対応 事例」
- 「若者参画 ワークショップ 進め方」
- 「地方議員 行政視察 先進事例 おすすめ」
- 「社員研修 地域密着 体験型」
- 「子ども 意見 聞き方 行政」

## 6. コンバージョン設計

### 6-1. コンバージョンポイント

| 種別 | 手段 | 優先度 |
|------|------|--------|
| メインCV | 問い合わせフォーム送信 | 最重要 |
| サブCV | 電話発信（`tel:` タップ） | 重要（特にモバイル） |
| マイクロCV | サービス詳細ページへの遷移 | 関心度の指標 |

### 6-2. 問い合わせまでの心理フロー

```
「何か手伝ってくれるところないかな」（検索/SNS）
  ↓
「お、行政支援やってるところがある」（ヒーローで認知）
  ↓
「自分の悩みと同じだ」（お悩みセクションで共感）
  ↓
「こういうサービスがあるのか」（サービスセクションで理解）
  ↓
「元教員でNPOもやってるのか。信頼できそう」（代表紹介で信頼）
  ↓
「相談してみようかな」（CTAで行動）
  ↓
「フォームが簡単だし、気軽に聞けそう」（フォームで完了）
```

### 6-3. 離脱を防ぐ設計原則

| 原則 | 具体策 |
|------|--------|
| **ハードルを下げる** | 「見積もり依頼」ではなく「ご相談」。初回相談無料を明示 |
| **不安を消す** | 実績数字、事例、FAQ。「他にも使っている人がいる」安心感 |
| **迷わせない** | CTAボタンはページ内に複数配置。スクロールのどこからでも問い合わせに飛べる |
| **フォームは最小限** | 名前、連絡先、相談内容の3項目で十分。選択肢は極力プルダウン |

## 8. 代表・酒井慶太の訴求戦略

マナビトは代表個人の専門性と人柄が最大の資産である。サイト上での打ち出し方を設計する。

### 8-1. 代表が持つ3つの武器

| 武器 | 内容 | サイトでの表現 |
|------|------|----------------|
| **教育者としての5年間** | 高校教員として現場を知っている。「人を育てる」プロ | ストーリー第1章で語られている（現状OK） |
| **NPO代表としての実行力** | 行政と若者をつなぐ実績。街づくりの現場で動いてきた | ストーリー第2〜3章で語られている（現状OK） |
| **両方をつなぐ翻訳者** | 行政の言葉、教育の言葉、若者の言葉を翻訳できる | **ここが最大の差別化。もっと前面に出すべき** |

### 8-2. 追加すべき情報

- **具体的な数字**: 教員歴○年、NPO活動○年、連携自治体○件、研修参加者○名
- **メディア掲載・登壇実績**: あれば一覧で掲載
- **資格・受賞歴**: あれば掲載
- **写真**: 活動中の写真を複数掲載。スーツではなく現場での姿が信頼感を生む

## 9. 競合との差別化マップ

| 比較軸 | 大手研修会社 | コンサルファーム | 個人講師 | **マナビト** |
|--------|------------|--------------|---------|-------------|
| 料金 | 高い | 高い | 安い | 中程度 |
| カスタマイズ性 | テンプレート中心 | 高い | 中程度 | **高い（個別設計）** |
| 行政理解 | 低い | 中程度 | 人による | **高い（NPO実績）** |
| 教育の専門性 | 研修特化 | 低い | 人による | **高い（元教員）** |
| 伴走力 | 納品型 | 提案型 | 単発型 | **伴走型（企画〜振返り）** |
| 地域密着 | 全国画一 | 都市部中心 | 人による | **地域に根ざす** |

**マナビトの勝ちパターン:**
「大手に頼むほどの予算はないが、テンプレート研修では意味がない」層に対して、教育と行政の両方を理解する伴走者として選ばれる。

- [ ] 実績数字の洗い出しと掲載
